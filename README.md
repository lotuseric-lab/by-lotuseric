# By LOTUSERIC — Cross-platform PWA Prototype 0.2

Responsive OKX perpetual market dashboard prototype for phones, tablets and desktop.

## Current features
- Active linear USDT-settled OKX SWAP instruments
- REST candle history and OKX WebSocket candle updates
- Timeframes: 1m, 3m, 5m, 15m, 30m, 1H, 2H, 4H, 6H, 12H, 1D, 1W, 1M
- EMA 9/21/55 toggles
- Responsive PWA shell and service-worker caching

## Limitations
This is an early prototype, not a completed trading platform. Alerts, Telegram, Pine Script compatibility, per-coin templates, multi-indicator layouts, demo trading and journal are not implemented yet. Pine v5/v6 compatibility is not guaranteed. No orders are sent and no OKX API key is required. Browser background execution and cross-device synchronization are not included.

## GitHub Pages
Serve the repository root over HTTPS. Open the resulting URL on each device and use the browser's install/add-to-home-screen option where supported.
